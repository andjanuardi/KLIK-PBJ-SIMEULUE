# KLIK-PBJ SIMEULUE

**Klinik Layanan Integrasi Konsultasi Pengadaan Barang dan Jasa — Kabupaten Simeulue.**

## Fitur Publik (tanpa daftar akun)

- **Beranda informatif** — statistik kinerja layanan, grafik penyelesaian per kategori, dan daftar konsultasi publik yang identitas pemohonnya disamarkan
- **Akses cepat 5 layanan** — Pengadaan Barang, Jasa Konstruksi, Jasa Konsultansi, Jasa Lainnya, dan Pasca Kontrak langsung ke form yang sesuai
- **Ajukan konsultasi < 2 menit** — isi 4 langkah mudah (identitas, informasi pengadaan, uraian, periksa kembali), langsung dapat Kode Tiket Unik; isian tersimpan otomatis bila tertutup
- **Lacak tiket mandiri** — masukkan kode tiket + 4 digit WA/NIK untuk melihat jawaban petugas dan bertanya lanjutan
- **Dokumen referensi** — dasar hukum dan panduan PBJ dari Drive resmi, bisa difilter per kategori dan diunduh

## Fitur Petugas

- **Kelola konsultasi** — antrean tiket terbaru, pencarian, penanda tiket yang menunggu respons, balas jawaban, dan ubah status (Dalam Proses / Perlu Klarifikasi / Selesai)
- **Kelola pengguna** — tambah dan atur akun operator (khusus admin)
- **Pengaturan tampilan** — ganti logo, teks beranda, teks berjalan disclaimer, tambah jenis layanan, dan jam layanan (khusus admin)
- **Kelola dokumen** — tambah, cari, ubah, dan hapus dokumen referensi berupa file atau tautan (khusus admin)
